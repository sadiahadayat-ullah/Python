# Python Object-Oriented Programming (OOP)

## 📘 Description

This repository contains beginner-friendly Python programs that demonstrate the core concepts of Object-Oriented Programming (OOP). It covers classes, objects, methods, inheritance, polymorphism, encapsulation, abstraction, and other important OOP concepts through practical examples.

## 📚 Topics Covered

* Introduction to OOP
* Classes and Objects
* Constructors (`__init__`)
* Instance Variables
* Class Variables
* Instance Methods
* Class Methods
* Static Methods
* Encapsulation
* Access Modifiers
* Inheritance
* Types of Inheritance
* Method Overriding
* Polymorphism
* Abstraction
* Abstract Classes
* `super()` Function
* Dunder Methods
* OOP Practice Programs

## 🛠️ Technologies Used

* Python 3
* PyCharm

## ▶️ How to Run

1. Clone this repository.
2. Open the project in PyCharm or Visual Studio Code.
3. Navigate to any folder.
4. Run any Python (`.py`) file.
