# Python Iterators

## 📘 Description

This repository contains beginner-friendly Python programs that demonstrate the use of iterators in Python. It covers iterable objects, iterator objects, the `iter()` function, the `next()` function, and creating custom iterators through simple and practical examples.

## 📚 Topics Covered

* Introduction to Iterators
* Iterables and Iterators
* `iter()` Function
* `next()` Function
* `StopIteration`
* Iterating Through Collections
* Creating Custom Iterators
* `__iter__()` Method
* `__next__()` Method
* Iterator vs. Iterable
* Iterator Practice Programs

## 🛠️ Technologies Used

* Python 3
* PyCharm

## ▶️ How to Run

1. Clone this repository.
2. Open the project in PyCharm or Visual Studio Code.
3. Navigate to any folder.
4. Run any Python (`.py`) file.
