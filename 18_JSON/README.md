# 🧩 Python JSON

## 📘 Description

This section contains my Python JSON learning journey, including beginner-friendly programs, practice exercises, and examples covering JSON data handling in Python.

The topics progress from basic JSON conversion and file operations to nested JSON, lists and dictionaries, updating and searching JSON data, and handling JSON-related exceptions.

## 📚 Topics Covered

- Introduction to JSON
- JSON Data Format
- JSON Objects
- JSON Arrays
- JSON Strings
- JSON Numbers
- JSON Boolean Values
- JSON `null`
- Python and JSON Data Type Mapping
- `json.dumps()`
- `json.loads()`
- `json.dump()`
- `json.load()`
- Writing JSON to Files
- Reading JSON from Files
- JSON Data Types
- Nested JSON
- JSON Lists and Dictionaries
- Accessing JSON Data
- Updating JSON Data
- Searching JSON Data
- JSON Exception Handling
- `FileNotFoundError`
- `JSONDecodeError`
- `OSError`
