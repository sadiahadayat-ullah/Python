# Python Decorators

## 📘 Description

This repository contains beginner-friendly Python programs that demonstrate decorators in Python. It covers first-class functions, higher-order functions, nested functions, creating custom decorators, handling function arguments, preserving return values, and using practical decorators to modify or extend function behavior.

## 📚 Topics Covered

- Introduction to Decorators
- First-Class Functions
- Higher-Order Functions
- Nested Functions
- Creating Custom Decorators
- Decorators with `*args`
- Decorators with `**kwargs`
- Returning Values from Decorated Functions
- Multiple Decorators
- Timing Decorators
- Access Control Decorators
- `functools.wraps`
- Logging Decorators
- Practical Decorators
- Decorator Challenge

## 🛠️ Technologies Used

- Python 3
- PyCharm

## ▶️ How to Run

1. Clone this repository.
2. Open the project in PyCharm or Visual Studio Code.
3. Navigate to the `16_Decorators` folder.
4. Run any Python (`.py`) file.
