# Python File Handling

## 📘 Description

This repository contains beginner-friendly Python programs that demonstrate file handling in Python. It covers reading, writing, appending, and managing text files through simple and practical examples to help beginners understand how to work with files efficiently.

## 📚 Topics Covered

- Introduction to File Handling
- Opening Files
- Reading Files
- Writing Files
- Appending to Files
- Closing Files
- File Modes (`r`, `w`, `a`, `x`)
- `with` Statement
- Counting Lines, Words, and Characters
- Copying File Contents
- File Practice Programs

## 🛠️ Technologies Used

- Python 3
- PyCharm

## ▶️ How to Run

1. Clone this repository.
2. Open the project in PyCharm or Visual Studio Code.
3. Navigate to any folder.
4. Run any Python (`.py`) file.
