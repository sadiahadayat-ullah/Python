# Python Exception Handling

## 📘 Description

This repository contains beginner-friendly Python programs that demonstrate exception handling in Python. It covers handling runtime errors, using different exception blocks, and writing robust programs through simple and practical examples to help beginners understand error handling.

## 📚 Topics Covered

- Introduction to Exception Handling
- `try` Block
- `except` Block
- `else` Block
- `finally` Block
- Raising Exceptions (`raise`)
- Handling Multiple Exceptions
- Built-in Exceptions
- User-Defined Exceptions
- Exception Handling Practice Programs

## 🛠️ Technologies Used

- Python 3
- PyCharm

## ▶️ How to Run

1. Clone this repository.
2. Open the project in PyCharm or Visual Studio Code.
3. Navigate to any folder.
4. Run any Python (`.py`) file.
