# Python Basics

## 📘 Description

This repository contains beginner-friendly Python programs that cover the fundamental concepts of Python programming. It is designed to help beginners understand Python syntax, variables, data types, operators, strings, and user input through simple and easy-to-understand examples.

## 📚 Topics Covered

- Variables
- Data Types
- Input and Output
- Type Casting
- Comments
- Operators
  - Arithmetic Operators
  - Assignment Operators
  - Comparison Operators
  - Logical Operators

## 🛠️ Technologies Used

- Python 3
- PyCharm


## ▶️ How to Run

1. Clone this repository.
2. Open the project in PyCharm or Visual Studio Code.
3. Run any Python (`.py`) file.
