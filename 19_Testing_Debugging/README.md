# Python Testing & Debugging

## 📘 Description

This repository contains beginner-friendly Python programs that demonstrate **Testing and Debugging** concepts. It covers debugging techniques, different types of errors, assertions, unit testing with `unittest`, testing exceptions, test setup and cleanup, and a practical calculator testing project.

## 📚 Topics Covered

* Introduction to Debugging
* Debugging with `print()`
* `breakpoint()` Function
* Python Debugger (`pdb`)
* Syntax Errors
* Runtime Errors
* Logical Errors
* Assertions
* `assert` Statement
* `AssertionError`
* Custom Assertion Messages
* Introduction to Testing
* Automated Testing
* Unit Testing
* `unittest` Module
* `unittest.TestCase`
* Test Methods
* `unittest.main()`
* `assertEqual()`
* `assertNotEqual()`
* `assertTrue()`
* `assertFalse()`
* `assertIn()`
* `assertNotIn()`
* Multiple Test Cases
* Testing Exceptions
* `assertRaises()`
* `ZeroDivisionError` Testing
* `setUp()` Method
* `tearDown()` Method
* Test Lifecycle
* Calculator Testing Project
* Testing Functions from Another Module

## 🛠️ Technologies Used

* Python 3
* PyCharm
* `unittest` — Python Standard Library

## ▶️ How to Run

1. Clone this repository.
2. Open the project in PyCharm or Visual Studio Code.
3. Navigate to the `18_Testing_Debugging` folder.
4. Open any Python (`.py`) file.
5. Run the program.

For testing programs using `unittest`, run the test file directly.

## 🧪 Testing Project

The **Calculator Testing Project** contains four calculator functions:

* `add()`
* `subtract()`
* `multiply()`
* `divide()`

The test file verifies the expected results and also tests division by zero using `assertRaises()`.

## 🎯 Learning Outcome

After completing this section, I can:

* Identify common Python errors.
* Debug programs using `print()` and `breakpoint()`.
* Use assertions to verify program behavior.
* Write unit tests using `unittest`.
* Test multiple inputs and expected results.
* Test expected exceptions.
* Use `setUp()` and `tearDown()`.
* Build a basic automated testing project.
