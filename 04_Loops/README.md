# Python Loops

## 📘 Description

This repository contains beginner-friendly Python programs that demonstrate the use of loops in Python. It covers different looping concepts through practical examples to help beginners understand iteration, repetition, and problem-solving using loops.


## 📚 Topics Covered

- `for` Loop
- `while` Loop
- Nested Loops
- `break` Statement
- `continue` Statement
- `pass` Statement
- Loop Control
- Pattern Programs
- Number-Based Programs
- Menu-Driven Programs


## 🛠️ Technologies Used

- Python 3
- PyCharm


## ▶️ How to Run

1. Clone this repository.
2. Open the project in PyCharm or Visual Studio Code.
3. Navigate to any folder.
4. Run any Python (`.py`) file.
