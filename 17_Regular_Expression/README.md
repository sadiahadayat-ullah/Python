# Python Regular Expressions (Regex)

## 📘 Description

This folder contains beginner-friendly Python programs that demonstrate Regular Expressions (Regex) using Python's built-in `re` module. It covers searching, matching, finding patterns, character classes, quantifiers, anchors, groups, validation, text replacement, splitting, data extraction, and practical text cleaning through examples and projects.

- Introduction to Regular Expressions
- `re` Module
- `re.search()`
- `re.match()`

- `re.finditer()`
- Character Classes

- `[a-z]`

- Anchors

- `$` End Anchor

- `re.split()`
- Capturing Groups
- `group()`

- `groups()`
- Named Groups
- `group("name")`
- `groupdict()`
- Email Extraction
- Phone Number Extraction

- Regex Validation
