# Python Modules & Packages

## 📘 Description

This repository contains beginner-friendly Python programs that demonstrate the use of modules and packages in Python. It covers creating, importing, and organizing modules and packages through simple and practical examples to help beginners write modular, reusable, and well-structured code.

## 📚 Topics Covered

- Introduction to Modules
- Built-in Modules
- User-Defined Modules
- Import Statement
- Importing Specific Functions
- Aliasing Modules
- `from...import` Statement
- Creating Packages
- Importing from Packages
- `__init__.py`
- Module and Package Practice Programs

## 🛠️ Technologies Used

- Python 3
- PyCharm

## ▶️ How to Run

1. Clone this repository.
2. Open the project in PyCharm or Visual Studio Code.
3. Navigate to any folder.
4. Run any Python (`.py`) file.
