# Python Conditions
## 📘 Description
This repository contains beginner-friendly Python programs that demonstrate the use of conditional statements. It covers different types of decision-making statements in Python through simple and practical examples to help build logical thinking and problem-solving skills.


## 📚 Topics Covered

- `if` Statement
- `if-else` Statement
- `if-elif-else` Statement
- Nested `if`
- Short-hand `if`
- Short-hand `if-else`


## 🛠️ Technologies Used

- Python 3
- PyCharm

## ▶️ How to Run

1. Clone this repository.
2. Open the project in PyCharm or Visual Studio Code.
3. Navigate to any folder.
4. Run any Python (`.py`) file.
