# Python Generators

## 📘 Description

This repository contains beginner-friendly Python programs that demonstrate the use of generators in Python. It covers generator functions, the `yield` statement, generator expressions, and lazy evaluation through simple and practical examples.

## 📚 Topics Covered

* Introduction to Generators
* Generator Functions
* `yield` Statement
* `next()` Function
* Generator Expressions
* Iterating Through Generators
* Generator vs. Lists
* Practical Generator Programs

## 🛠️ Technologies Used

* Python 3
* PyCharm

## ▶️ How to Run

1. Clone this repository.
2. Open the project in PyCharm or Visual Studio Code.
3. Navigate to any folder.
4. Run any Python (`.py`) file.
