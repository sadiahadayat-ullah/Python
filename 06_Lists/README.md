# Python Lists

## 📘 Description

This repository contains beginner-friendly Python programs that demonstrate the use of lists in Python. It covers list creation, indexing, slicing, methods, and common list operations through simple and practical examples to help beginners understand one of Python's most widely used data structures.


## 📚 Topics Covered

- List Basics
- Creating Lists
- List Indexing
- List Slicing
- List Methods
- Adding Elements
- Removing Elements
- Updating Elements
- Looping Through Lists
- Nested Lists
- List Operations
- List Practice Programs


## 🛠️ Technologies Used

- Python 3
- PyCharm


## ▶️ How to Run

1. Clone this repository.
2. Open the project in PyCharm or Visual Studio Code.
3. Navigate to any folder.
4. Run any Python (`.py`) file.
