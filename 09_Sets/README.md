# Python Sets

## 📘 Description

This repository contains beginner-friendly Python programs that demonstrate the use of sets in Python. It covers set creation, methods, and common set operations through simple and practical examples to help beginners understand how to work with unique and unordered collections of data.


## 📚 Topics Covered

- Set Basics
- Creating Sets
- Adding Elements
- Removing Elements
- Updating Sets
- Set Methods
- Union
- Intersection
- Difference
- Symmetric Difference
- Set Operations
- Practical Set Programs


## 🛠️ Technologies Used

- Python 3
- PyCharm


## ▶️ How to Run

1. Clone this repository.
2. Open the project in PyCharm or Visual Studio Code.
3. Open any Python `(.py)` file.
4. Run the file.
