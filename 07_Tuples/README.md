# Python Tuples

## 📘 Description

This repository contains beginner-friendly Python programs that demonstrate the use of tuples in Python. It covers tuple creation, indexing, slicing, methods, and common tuple operations through simple and practical examples to help beginners understand immutable data structures in Python.


## 📚 Topics Covered

- Tuple Basics
- Creating Tuples
- Tuple Indexing
- Tuple Slicing
- Tuple Methods
- Packing and Unpacking Tuples
- Nested Tuples
- Tuple Operations
- Tuple Practice Programs

## 🛠️ Technologies Used

- Python 3
- PyCharm


## ▶️ How to Run

1. Clone this repository.
2. Open the project in PyCharm or Visual Studio Code.
3. Navigate to any folder.
4. Run any Python (`.py`) file.
